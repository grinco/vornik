# AI transparency

**Last updated:** 28 July 2026

If you arrived here from a message that said *"You are interacting with an AI
system"* — this page explains what that means.

## You are talking to software, not a person

Vornik is an AI agent platform. When you converse with it over Telegram, Slack,
email, a GitHub comment thread, or the web chat, your messages are sent to a
large language model and the reply you receive is generated by that model.

**No human reads or writes those replies in real time.** A human operator
configures the system, can review what it did afterwards, and may intervene —
but the conversation itself is machine-generated.

This notice is given under **Article 50(1) of the EU AI Act**
(Regulation (EU) 2024/1689), which requires providers of AI systems intended to
interact directly with people to make that interaction transparent.

## What the AI can and cannot do

Vornik can carry out real work: it schedules tasks, runs tools, reads and
writes files, opens pull requests, sends messages, and searches a memory of
past work. This is not a passive chatbot — it acts.

It is also **wrong sometimes**. Language models produce fluent text regardless
of whether the underlying claim is true. Vornik ships several guards against
this (output scanning, hallucination detection, human approval gates on
sensitive actions), and none of them is perfect.

**Do not treat its output as professional advice** — legal, medical, financial,
or otherwise. Verify anything that matters before you rely on it.

## Where your messages go

To generate a reply, the content of your conversation is sent to a third-party
model provider. Which one depends on how the operator of this deployment has
configured it. The possible recipients are:

| Provider | Role |
|---|---|
| Anthropic (Claude) | Language model inference |
| OpenAI | Language model inference |
| Amazon Web Services (Bedrock) | Language model inference |
| OpenRouter | Model routing to further downstream providers |
| Locally-hosted models (e.g. Ollama) | Inference with no external transmission |

An operator running local models only can process your messages without any
external transmission at all. Ask the operator of the deployment you are
talking to which configuration applies.

This list is also the sub-processor list for data-protection purposes — see
the [compliance status](compliance.md) page.

## Human oversight

- Sensitive and irreversible actions are gated behind explicit human approval.
- Every tool call the system makes is recorded in an audit log.
- The operator can pause, cancel, or steer any task while it runs.
- AI-authored content published to public repositories passes a human review
  gate before it is merged.

## Your rights

Depending on where you live, you may have rights over the personal data
processed here — access, correction, erasure, portability, objection. In a
self-hosted deployment the **operator of that deployment is the data
controller**, so those requests go to them, not to the Vornik project. The
[compliance status](compliance.md) page sets out the current state honestly,
including what is not yet in place.
