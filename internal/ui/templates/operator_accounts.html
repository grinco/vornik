Accounts

{{if gt .AwaitingCount 0}} {{.AwaitingCount}} awaiting {{end}} ← Dashboard

Accounts are what every door resolves to: a web session, a linked Telegram or Slack sender, an owned API key. Create an account here, grant it user access scoped to projects or instance-wide admin, and link channels by issuing a one-time code below, which the person redeems from chat — /link <code> on Telegram, and this deployment's configured slash command followed by link <code> on Slack. Revoking an account revokes every door at once. Every change is recorded in the admin audit log.
